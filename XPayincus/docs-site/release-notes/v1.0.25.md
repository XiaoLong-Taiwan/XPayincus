# v1.0.25 Caddy and Incus Host Installation Fixes

- Caddy installation now checks the initial APT update before registering service cleanup traps or making Caddy package and service changes. Repository update failures stop with an actionable error.
- Caddy's downloaded signing key and repository source receive explicit readable permissions, including when the installer runs with a restrictive umask.
- Incus installation rejects a symlink at `/etc/apt/keyrings`, creates the keyring directory with explicit permissions, and downloads and converts the Zabbly key in a private temporary directory before atomically replacing the destination key.
- Incus installation now stops if key download/conversion, source-file writing, APT update, or package installation fails. The temporary key workspace is removed on exit.
- These changes affect the host installation templates. This release note records source changes and does not assert that tests ran or that the changes have been published or deployed.
