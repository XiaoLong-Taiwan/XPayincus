# v1.0.38 Monitoring, Host Status and Instance Controls

- Improve Agent sampling and instance matching across live streams, snapshots and historical charts. Clear stale live values when monitoring data expires.
- Add a customer Host Status page for hosts running the customer's own instances. It shows CPU, memory, disk and swap usage, network receive and transmit rates, and sample times, with filters for country or region and plan.
- Open the terminal directly from instance details. On phones, the terminal adapts to the on-screen keyboard and groups search, log export, reconnect and other controls in an actions menu.
- Group start, stop, restart, force stop and force restart in the instance power menu. Forced actions require confirmation. The upgrade includes the `20261124000000_add_instance_task_power_force` database migration so queued tasks retain the selected mode. Existing tasks and API requests that omit the force flag keep the previous forced behavior.
- Synchronize product, Agent, RFW/ZFS, Compose image and package versions to v1.0.38. GitHub Actions handles release checks, builds and packaging.
