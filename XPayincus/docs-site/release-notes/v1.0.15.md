# v1.0.15 發布說明（發行目標）

## 儲存池用途更新

- 將 `purpose` 納入資料庫更新；先確認儲存池已登記，未登記時回傳 404，更新時關聯已失效則報錯。
- 僅變更用途或描述未變時不呼叫 Incus 更新；容量或描述變更時才更新 Incus。

## 監控 HTTP client

- Agent 監控查詢使用共用 HTTP client，沿用統一 API base URL、認證、refresh 與錯誤處理，保留查詢參數、AbortSignal 及 30 秒逾時。

## 宿主捷徑與 UI 入口

- `incudal`／`k` 捷徑使用統一倉庫的 `XPayincus/server/templates/install.sh` 路徑，以 HTTPS 下載至私人暫存檔，核對非空、shebang 與 Bash 語法後才原子替換快取。
- 下載或檢查失敗保留舊快取但不自動執行；保留既有其他 `k` 命令，提供 `--install-shortcuts` 僅修復捷徑。
- 宿主資訊頁移除維護計畫目標／實例選擇、預檢與建立入口，以及相關額外資料請求；保留既有計畫列表與 review／takeover／rollback／resume／cleanup 操作。

## 版本與驗證範圍

- 三份 VERSION 同步為 `v1.0.15`；四份 package.json、RFW 三個自家 crate 與 Cargo.lock 同步為 `1.0.15`，Go Agent 預設版本、Compose 標籤、fixture 及現行文件一併同步。
- 保留第三方依賴、歷史紀錄、既有宿主資產釘選、完整 30 件資產集合及最低 updater `v0.0.3`；v1.0.14 原發行稿保留。
- 本次只編輯版本與文件並靜態核對差異，保留工作區既有功能修改；未執行測試、型別檢查、建置或封裝，未提交、推送、發布、部署或 OTA，未重新查核遠端 Release。正式發布狀態以 GitHub Release 為準，CI 與隔離真機驗收待後續確認。
