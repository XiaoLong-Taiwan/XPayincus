# v1.0.13 發布說明

## ZFS 儲存池修正

- ZFS loop 預設大小改依 `/var/lib/incus` 所在磁碟的剩餘空間動態計算：取一半後向下取整至 GiB，上限 10GiB。例如剩餘 19GiB 時預設 9GiB，剩餘 5GiB 時預設 2GiB。
- 有效大小至少 1GiB，且不得超過剩餘空間的一半。互動輸入格式錯誤、過小或超出容量時重新提示；空白採用動態預設，輸入結束時停止。明確指定的無效 `INCUS_STORAGE_SIZE` 直接失敗，不進入互動重試。
- 自動選擇儲存 driver 且未指定大小時，若剩餘空間的一半不足 1GiB，改用 `dir` 儲存池；明確指定 ZFS 或大小時則報錯，避免靜默切換。
- 磁碟容量查詢失敗或回傳資料無效時，在建立儲存池前停止。
