# v1.0.37 Instance Operations and Mobile Console

- Allow administrators to queue controlled rebuilds for instances owned by other users while preserving stopped-state, transfer-lock, conflict, image-compatibility and operation-verification checks.
- Add root password changes for delivered instances and isolate corrupt monitoring journals before rebuilding readable monitoring state.
- Improve the instance purchase stepper, instance detail actions, terminal navigation and narrow-screen spacing for mobile workflows.
- Synchronize product, Agent, RFW/ZFS, Compose image and package versions to v1.0.37.
- Tests, type checks, builds, packaging and release artifacts run in GitHub Actions. This release does not assert production deployment or OTA completion.
