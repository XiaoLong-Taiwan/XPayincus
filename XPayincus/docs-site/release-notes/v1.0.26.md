# v1.0.26 Unified Version Alignment and Agent Host Management

- Align unified product version sources for Dashboard/API, Agent, RFW, and ZFS to v1.0.26.
- Update Compose image tags and OCI image version labels to v1.0.26.
- Represent Agent-only hosts with `agent://` identifiers and route Incus, Caddy, and terminal operations through the Agent WSS tunnel instead of treating the identifier as a direct HTTP URL.
- Keep address monitoring and host address parsing limited to HTTP(S) host URLs, while allowing Agent reports to supply NAT address defaults and the `10000..65535` port range in host configuration.
- Harden Caddy installation and configuration handling around APT keyring permissions, repository updates, timeout responses, and site parsing.
- Remove Agent history, monitoring, and maintenance plan/action panels from host details.
- Keep the minimum updater at v1.0.3 and preserve prior release history.
- This note records source-tree changes only; it does not assert that tests ran or that the release has been published or deployed.
