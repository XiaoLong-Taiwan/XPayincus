# v1.0.21 宿主驗證、管理入口與部署文件

本版為發行目標，正式發布狀態以 GitHub Release 為準。以下整理工作區既有修改；本次僅同步版本與編輯文件，不新增或修改功能邏輯，也不宣稱既有修改已通過測試或真機驗收。

## 宿主與 Caddy 驗證

- 宿主詳細資料提供已安裝狀態，已安裝節點可重新驗證，不再受首次安裝會話到期限制；驗證更新連線狀態時保留維護等管理狀態。
- Caddy 頁提供「驗證並啟用」入口，透過 Agent WSS 讀取本機 Caddy 設定。隧道離線回報 503，其他驗證失敗回報 502；離線提示先恢復 Agent 連線，避免誤判為需重裝 Caddy。
- Server／Agent 沿用既有出站 WSS 協定，須核對相容版本與實際管理操作；後端仍限單一 Node 程序。

## Dashboard 與 Agent 管理入口

- Dashboard／Compose 短入口提供 `update`、`update-plan`、`doctor`、`recover` 與 `force-recreate`，轉交指定可信部署目錄的 `panel.sh`；核對入口、符號連結及祖先路徑的擁有者與權限。
- 無版本 `update` 走官方最新正式版核驗、備份與更新；固定版本介面仍只準備部署檔案。`force-recreate` 重建目前釘選版本，保留資料與密鑰，仍須先備份，且不等於資料庫回滾。
- Agent 選單支援本機 binary 的 `--sha256`，僅供 `local` 使用，驗證 64 位十六進位雜湊並傳給 installer；設定路徑依序採 `INCUDAL_CONFIG_FILE`、`INCUDAL_CONFIG_DIR/config.yaml` 與預設路徑。
- Agent 下載 installer 後先確認非空及 Bash 語法，補齊中斷清理；同版修復仍須明確指定已安裝版本，未指定版本會選擇 latest。

- 更新 Dashboard／Agent 安裝、容量規劃、更新、同版修復、失敗恢復與備份限制文件，區分來源樹、正式 Release、CI 及目標環境驗收；硬體建議未經容量壓測。
