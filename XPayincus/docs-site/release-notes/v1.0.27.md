# v1.0.27 Host Capacity and Panel UX Fixes

- Fix desktop scrolling and normal-mode translation keys on the instance creation page.
- Use the complete host, storage, network, IP, and NAT capacity checks when determining whether public packages are sold out.
- Fix themed backgrounds and restore clipboard icons for user and admin hosting application navigation.
- Allow each host to configure its sellable CPU quota during creation and updates while rejecting quotas below effective reserved usage.
- Preserve configured host quotas during resource recalculation.
- Route Caddy Admin API requests through the Agent tunnel with the required `127.0.0.1:2019` Host authority.
- Improve panel trust HTTP 403 diagnostics without exposing response bodies, credentials, or Agent secrets.
- Tests, type checks, builds, packaging, and release artifacts are executed by GitHub Actions. This note does not assert production deployment or OTA.
