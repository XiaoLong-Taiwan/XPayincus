# v1.0.24 Compose deployment compatibility

- Accept existing Compose deployments regardless of owner UID or directory write mode, including shared parent directories with mode `0777`.
- Keep the absolute path, required file, symlink boundary and `.env` checks. Option `[10]` remains read-only and can inspect an incomplete deployment.
- Verify ownership and trust separately before running deployment operations with elevated privileges. The deployment check validates layout only.
- Add regression coverage for writable directories, sticky directories and alternate owners.
