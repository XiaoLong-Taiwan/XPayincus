- 未完成更新 journal 的阻擋訊息與唯讀 `recover` 指引使用部署 `panel.sh` 的絕對路徑，透過 shell 安全引用處理空白、單引號與其他特殊字元，不依賴 shell 當前目錄。
- 數字選單更新失敗時提示保留 journal 與備份，先選 `[0]` 退出腳本，再於 shell 執行完整命令；先查看 `recover`、`status`、`doctor` 與 `logs api`。

## Agent bootstrap 首次信任

- 安裝器使用一次性 `ait_` TOKEN 呼叫 `/api/agent/install-config/:token?bootstrap=1`。API 先驗證面板憑證配對，失敗回傳 503 且不消耗 TOKEN；通過後才兌換 Agent ID、secret、base64 面板憑證及宿主已安裝狀態，回應禁止快取。
- 安裝器嚴格解析四行固定格式，不執行回傳的 shell 程式碼；缺少 bootstrap 欄位、舊兩行格式或無效狀態即停止並提示更新面板。
- TOKEN 兌換後先安裝宿主捷徑；首次節點透過內部 `--bootstrap-agent-trust` 匯入初始面板憑證，沿用既有憑證與 trust 檢查，不需要尚未完成配對的 Agent HMAC。捷徑或憑證匯入失敗時，在替換／啟動 Agent 前停止；宿主準備流程也會在 Incus 初始化後安裝捷徑。
- 首次節點啟動後顯示「待驗證」，不立即刷新 HMAC 信任或移除舊 trust。請由節點擁有者／管理員在面板完成連線驗證，成功後再於宿主執行 `incudal --refresh-agent-trust`；初始憑證匯入與 Agent 啟動不代表面板驗證完成。
- 已安裝節點仍使用既有 HMAC 刷新；403、簽名或連線驗證失敗仍會報錯，不能轉成首次安裝成功。舊信任仍須在新連線驗證成功後才移除。
