# v1.0.39 主機即時監控與實例詳情

- Agent 每 3 秒回報主機的 CPU、記憶體、磁碟、Swap 與網路收發速率。客戶端「主機狀態」在頁面可見時每 3 秒更新，優先採用即時取樣，缺少新鮮取樣時改用仍有效的心跳資料。
- 管理員可在主機設定中切換客戶端監控可見性，並自訂顯示名稱與分類。客戶端「主機狀態」新增分類篩選。
- 面板升級需套用 Prisma 遷移 `20261125000000_add_host_monitoring_settings`。遷移會新增 `monitoring_visible`、`monitoring_display_name` 與 `monitoring_category` 欄位。既有主機的監控可見性預設開啟，自訂名稱與分類預設留空。
- 實例詳情在基本資訊中保留即時指標，並提供獨立的「歷史監控」分頁，顯示 CPU、記憶體、磁碟 I/O、網路趨勢、分時樣本與流量統計。窄螢幕上的電源選單與其他操作按鈕採一致尺寸排列。
- 同步產品、Agent、RFW／ZFS、Compose 映像與套件版本至 `v1.0.39`。GitHub Actions 負責發行驗證、建置與封裝。
