# v1.0.14 發布說明（發行目標）

## 安裝資訊與 TOKEN

- 安裝指令、面板地址與 TOKEN 分欄顯示，各欄可獨立複製，提供複製成功／失敗提示；Agent TOKEN 顯示到期時間。
- 安裝指令不再嵌入 TOKEN。安裝時另外輸入面板地址及隱藏 TOKEN，舊含 TOKEN 的宿主下載路由停用框架請求日誌；外部代理仍須遮蔽含 TOKEN 的 URL。
- 重新取得、關閉資訊、切換宿主及元件停用／卸載時清除前端安裝資訊，忽略過期請求回應。清除畫面狀態不撤銷已簽發 TOKEN，也不清除系統剪貼簿。

## 安裝流程修正

- 開始前顯示安裝摘要並要求確認；UUID 宿主初始化 TOKEN 與 `ait_` Agent TOKEN 依各自流程處理。
- 新裝準備 Incus／ZFS 後安裝 Agent，新儲存池預設 ZFS，沿用既有 pool 且不轉換 driver；重裝保留既有 Agent 設定。
- 宿主信任更新移至確認後，Agent 安裝完成後以既有憑證刷新 Incus 信任。
- 安裝輸出提供步驟提示、適應終端寬度的簡潔選單及無色輸出。容量輸入支援小數，區分十進位 GB 與二進位 GiB。
