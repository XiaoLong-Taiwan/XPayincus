# v1.0.17 信任刷新診斷

面板與宿主的信任刷新新增分階段診斷，協助區分憑證取得、HMAC 回應驗證、Incus 信任寫入及面板回連問題。Agent 本體已安裝啟動但信任未完成時，安裝器顯示雙向連線檢查提示，修復後可執行 `incudal --refresh-agent-trust`。

HTTP 錯誤僅顯示狀態碼；不輸出原始回應正文、標頭、URL、密鑰或例外文字。API 日誌只保留固定錯誤代碼、階段與 host ID。HMAC 驗證、禁止重新導向及驗證成功後才移除舊信任的順序維持不變。

同步所有產品版本與 Compose 標籤至 v1.0.17，維持完整 30 件資產、16 筆 SHA256SUMS 與最低 updater v0.0.3。既有 `update.py` 工作區修改未納入此次提交。

測試、型別檢查、雙架構建置、封裝及映像發布由 GitHub Actions 執行；對應提交 CI 成功後才建立發行 tag。正式發布與驗證證據以該 tag 的 Actions、GitHub Release 及 GHCR 為準。

本次不部署生產或執行 OTA。尚須在隔離真機驗證雙向 TLS、實際 Incus 信任刷新與網路失敗修復；CI 模擬測試不代表完成實機驗收。ZFS 交付仍為 builder 原始碼，不包含通用核心模組。
