# v1.0.23 Compose deployment diagnostics

- Add menu option `[10]` to inspect an existing Compose deployment without running its `panel.sh`, contacting Docker or creating any files. The check works when `.env` is missing or empty and never displays its contents.
- Report missing files, invalid symlinks, unexpected owners and unsafe write permissions. If the status menu finds deployment files but no usable `.env`, it reports the incomplete setup instead of querying containers.
- Keep `doctor` and the read-only form of `recover` available for prepared deployments. State-changing recovery commands require a nonempty `.env`.
- Document interactive Dashboard and Agent installation. Enter the Agent enrollment token only at the prompt, never in a URL or command line.
- Add regression coverage for the menu, deployment checks and recovery guards. No database schema or minimum updater change is included.
