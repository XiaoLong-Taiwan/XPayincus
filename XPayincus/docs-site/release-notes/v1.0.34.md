# v1.0.34 Monitoring and Trust Guards

- Display monitoring memory values in bytes and MB so raw resource measurements remain precise while the dashboard presents a readable unit.
- Correct the seven-day history query boundary to include the intended time window without crossing into adjacent samples.
- Improve host verification error reporting with structured diagnostics for failed verification flows.
- Add a trust refresh guard that prevents refresh operations from running when the required trust state is incomplete or invalid.
- Add and update guard tests covering memory units, seven-day history boundaries, host verification errors, and trust refresh behavior.
- Synchronize current product, Agent, RFW/ZFS, Compose image, OCI label, and package versions to v1.0.34.
- This release does not assert production deployment or OTA completion.
