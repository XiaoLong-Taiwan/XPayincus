# v1.0.28 Proxy Sites Removal and Release Cleanup

- Remove the retired Caddy and Proxy Sites API routes, database modules, client views, host controls, installation template, and related route guards.
- Add a forward-only Prisma migration that removes the retired `proxy_sites` table, enum, Caddy host columns, and legacy site quota columns without rewriting historical migrations.
- Add source, schema, and migration guards so future builds cannot silently reintroduce the retired feature.
- Preserve the existing Agent tunnel, Host CPU capacity, package capacity evaluation, instance creation, and hosting application fixes from v1.0.27.
- Tests, type checks, builds, packaging, release assets, and multi-architecture images are executed by GitHub Actions. This note records source changes only and does not assert deployment or OTA completion.
