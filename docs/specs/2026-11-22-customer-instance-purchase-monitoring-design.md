# 客戶實例與購買流程整合改版 — Design Spec

> Generated by brainstorm on 2026-11-22. Status: draft.

## Problem

客戶建立與管理實例時，IP、SSH 映射連接埠、即時資源使用與失敗原因資訊不足；建立流程也未清楚呈現選購、設定、確認與付款階段。託管申請介面與面板不一致，且系統仍提供不再需要的郵箱／SMTP 販售商品。

## Chosen Approach

採整合式改版，維持既有 Incus、Agent tunnel 與購買／帳務驗證邊界。實例詳情由既有 Instance DTO 提供 IPv4、可用時的 IPv6 與實際 SSH port mapping；Agent 監控樣本接入現有 monitoring journal，Server 新增經使用者／實例權限驗證的 SSE 訂閱端點，供面板即時呈現 CPU、網路上下行速率與累計流量、記憶體和 Agent 狀態。監控樣本短期持久化 7 天並定期清理，UI 顯示即時數值與近期趨勢；連線中斷時顯示 stale/offline 狀態並支援重連。

建立實例頁改為分步購買流程：選套餐、設定實例、確認資源與價格、付款／提交、建立中及成功／失敗結果。既有 idempotency、Turnstile、伺服器端方案與容量驗證及帳務流程必須保留。非可恢復建立錯誤以安全的錯誤碼、可讀訊息和關聯 task/request ID 儲存並回傳面板，不包含密鑰或敏感設定。

託管上架申請沿用登入後 AppLayout 與全站表單、載入、空狀態、錯誤和按鈕樣式。郵箱／SMTP 販售產品的使用者與管理介面、API、排程、供應商整合、分潤關聯及商品資料完整移除，透過前向資料庫 migration 清除商品資料；既有資料需在 migration 中明確刪除。系統 SMTP 設定、寄送能力、驗證信、通知信、信件佇列及相關設定 API 全數保留。

## Trade-offs Accepted

| Trade-off | Rationale |
|-----------|-----------|
| SSE 僅提供 Server 到瀏覽器的單向事件流 | 監控用途只需接收資料，可沿用既有 Agent 上報通道；瀏覽器操作仍走既有 HTTP API。 |
| 監控資料保留 7 天 | 可供近期趨勢與排錯，代價是資料表索引、清理工作及儲存容量管理。 |
| 郵箱商品資料使用不可逆的前向 migration 清除 | 符合完整移除要求；既有商品訂閱／相關歷史資料不再可查，執行前須在 migration 範圍明確限定商品資料，不能觸及系統信件資料。 |
| 跨前端、Server、Agent 與 schema 整合交付 | 端到端功能完整，但需要整體 CI、migration 與瀏覽器驗證通過後才能交付。 |

## Acceptance Criteria (EARS)

### Ubiquitous
- 系統 shall 保留站點 SMTP 設定、驗證信、通知信與其他 transactional email 功能。
- 系統 shall 對 SSE 與實例資料套用登入、擁有權及管理員權限檢查。
- 系統 shall 不向客戶回傳密鑰、初始化命令秘密值或其他敏感設定作為建立錯誤內容。

### State-driven
- While 實例具有 IPv4 或 IPv6 位址時，客戶詳情 shall 顯示所有可用位址。
- While 實例配置 SSH port mapping 時，客戶詳情 shall 顯示外部映射連接埠而非固定連接埠 22。
- While SSE 連線有效時，客戶詳情 shall 更新 CPU、網路上下行、記憶體與 Agent 連線狀態。
- While 監控樣本未超過 7 天時，系統 shall 可供近期監控趨勢查詢；過期樣本 shall 被定期清除。
- While 建立流程進行中，使用者 shall 可辨識目前步驟並查看方案、資源與價格摘要。

### Event-driven
- When Agent 上報新的實例監控樣本時，系統 shall 持久化樣本並透過 SSE 發送給已授權的訂閱者。
- When SSE 中斷時，面板 shall 嘗試重連並將資料標示為過期或離線，直到收到新樣本。
- When 實例建立工作失敗時，系統 shall 儲存安全錯誤碼、可讀訊息及 task/request 關聯識別碼，並讓客戶面板可查閱。
- When 使用者提交最終購買確認時，系統 shall 保留既有伺服器端驗證、幂等處理、安全驗證與付款行為。
- When 郵箱商品移除 migration 執行時，系統 shall 刪除商品專屬資料，且不修改系統 SMTP 與 transactional email 資料。

### Unwanted behaviour
- If 使用者無權存取實例，then SSE、監控歷史與建立錯誤 API shall 拒絕請求。
- If 實例沒有 IPv6，then 面板 shall 不顯示虛構或空白 IPv6 值。
- If Agent 離線或沒有新監控資料，then 面板 shall 清楚呈現資料中斷狀態而不偽裝成即時數據。
- If 商品移除後仍呼叫郵箱商品 API 或路由，then 系統 shall 不再提供可購買或管理郵箱商品的功能。

## Open Questions

No open questions — product scope and retention decisions were resolved in the dialogue. Implementation discovery will determine exact sample interval, existing SSH mapping field, and task error persistence model without changing the agreed behaviour.

## Out of Scope

- 不提供監控資料超過 7 天的查詢或長期分析。
- 不移除管理員設定的系統 SMTP、測試郵件與 transactional email。
- 不改變現有付款供應商、價格計算規則或主機 Agent tunnel 的認證協定。
- 不執行 production deployment、OTA、版本發布或 Git commit。
