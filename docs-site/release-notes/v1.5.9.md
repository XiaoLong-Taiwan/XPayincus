# v1.5.9

## 宿主機安裝

- **RFW 防火牆支援獨立可控安裝**：新增獨立安裝與卸載入口，可指定版本、網卡、SHA-256、國家黑白名單，以及郵件、HTTP、SOCKS5、FET、WireGuard、QUIC 和全流量屏蔽規則，支援非互動式自動化部署。
- **RFW 下載兼容新舊 Release 資產名稱**：依序嘗試目前 GitHub Actions 產物名稱與舊版二進位名稱，保留 ELF 與 SHA-256 驗證；預設版本缺少固定雜湊時拒絕安裝，自訂版本未提供雜湊時明確警告。
- **新增 ZFS ARC 記憶體配置**：安裝流程可依宿主機總記憶體自動建議 ARC 上下限，也可由管理端安裝參數指定，並在安裝確認畫面顯示最終設定。

## 管理端整合

- **節點安裝腳本 API 擴充**：管理端 API 型別與請求參數同步支援 ZFS ARC 設定，確保介面產生的安裝命令能傳遞宿主機記憶體配置。
- **安裝腳本守衛補強**：新增 RFW 獨立操作、下載校驗、參數解析與 ZFS ARC 設定的結構守衛，降低後續修改造成安裝流程退化的風險。

> 本版不涉及資料庫結構變更。基於 v1.5.8。
